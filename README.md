# Compsci-Tutoring-WK6
Code editor for WK6 lesson with Mr. Jonathan

## Python Workspace

Run the entry point to verify your setup:

```bash
python main.py
```

### Workspace files (`workspace/`)

| File | Topic |
|---|---|
| `01_variables.py` | Variables & Data Types |
| `02_control_flow.py` | if / elif / else, while, for loops |
| `03_functions.py` | Defining and calling functions |
| `04_lists_dicts.py` | Lists and Dictionaries |
| `scratch.py` | Free scratch pad for experimentation |

Open any file, read the examples, then complete the **"Try it yourself"** exercises at the bottom of each file.
